ARCANA ACADEMY

Game Design Document（GDD）v1.0

副題：失われた星と、魂を継ぐ魔法使い

* プロジェクト名：ARCANA ACADEMY
* ジャンル：AI連動型・長期育成ファンタジーRPG
* プレイヤー：1人
* 主人公：げんた自身をモデルにした完全オリジナルの魔法使い
* 世界観：独自の魔法文明・魔法学院
* ビジュアル：写実的3Dダークファンタジー
* 開発方式：段階的開発
* 基本方針：現実の経験とゲーム内の行動が相互に成長へ影響する

⸻

1. ゲームのコンセプト

ARCANA ACADEMYは、プレイヤー自身の現実の経験、思考、価値観、挑戦、ゲーム内での選択を通じて、1人の魔法使いを育成するゲームである。

一般的なRPGのように、あらかじめ決められた能力や性格を持つ主人公ではない。

プレイヤーの経験によって、主人公の能力、性格、魔法適性、外見、得意分野、人間関係が変化していく。

最終的に、プレイヤーごとに異なる唯一無二の魔法使いが誕生する。

2. ゲームの基本理念

1. キャラクターはプレイヤーの経験を反映する。
2. キャラクターには独自の人格と成長履歴がある。
3. 成長に正解・不正解を設けない。
4. プレイヤーの選択によって物語が変化する。
5. 成長結果は可視化され、いつでも確認できる。
6. 長期間プレイすることでキャラクターへの愛着が増す。
7. 過去の成長や記録が消えない設計にする。

3. 世界観

舞台は現実世界から隔絶された魔法文明「エルディア」。

その中心には、古代から続く魔法学院「アルカナ学院」が存在する。

学院は単なる教育機関ではなく、世界中の魔法使いが知識・技術・研究を共有する巨大な魔法都市でもある。

世界の主要エリア

* アルカナ学院：主人公の生活拠点
* 星辰の大図書館：魔法や歴史の研究
* 魔法薬研究棟：魔法薬の調合
* 禁書庫：封印された古代魔法の研究
* 魔法生物保護区：魔法生物との出会いと育成
* 決闘演習場：魔法戦闘
* 古代遺跡：探索・謎解き・物語進行
* 星影の庭園：精神・魔力の回復

世界観は独自に構築し、既存の小説・映画・ゲームの固有名称、キャラクター、意匠を流用しない。

4. 主人公システム

主人公はプレイヤー本人をモデルにしたオリジナル魔法使い。

初期設定では、プレイヤーから提供された情報を使用する。

ただし、プレイヤー本人とゲーム内キャラクターの情報は分離して管理する。

初期プロフィール

* 名前：げんた（変更可能）
* 性別：男性
* 誕生日：1997年7月3日
* 魔法使いとしての年齢：ゲーム内設定で管理
* 出身：未解明
* 魔法適性：初期診断で判定
* 所属寮：入学時の診断で決定
* 魔法の杖：初期イベントで決定

外見は独立したキャラクター設定として管理し、実際の人物写真を使用する場合は本人の明示的な許可を必要とする。

5. キャラクター能力システム

基本ステータス

能力	内容
知性	知識、分析、学習能力
精神	忍耐、冷静さ、精神耐性
感受性	感情理解、共感、芸術性
創造性	発想、表現、創作能力
意志力	決断、挑戦、継続力
絆	信頼、協力、人間関係
身体能力	体力、運動、反応能力

能力値は0〜100を基本とする。

能力の成長には上限を設け、特定能力だけを無制限に成長させない。

性格パラメータ

* 好奇心
* 探究心
* 独立心
* 共感性
* 負けず嫌い
* 冒険心
* 慎重さ
* 忍耐力
* 決断力
* 責任感

性格パラメータは基本的にプレイヤーの行動傾向から形成される。

短期的な行動だけで性格を断定しない。

性格は固定ではなく、長期的な行動履歴に応じて変化する。

6. 魔法体系

基本魔法系統

1. 星辰魔法：星、空間、天体、運命
2. 精神魔法：精神、記憶、感情、認識
3. 創造魔法：具現化、錬成、構築、創作
4. 自然魔法：植物、生命、動物、自然
5. 元素魔法：炎、水、風、土、雷
6. 古代魔法：未知の法則、特殊能力、禁術

魔法適性は初期診断で仮設定するが、成長によって変化する。

複数の魔法系統を組み合わせることで複合魔法を習得できる。

魔法習得条件

* 授業の受講
* 魔法研究
* 探索での発見
* 魔法生物との交流
* 特定の経験
* 物語上の選択
* 能力値の条件達成

7. 現実連動型成長システム

このゲームの最重要機能。

現実での経験をゲーム内の成長イベントへ変換する。

入力方法

* 手動で経験を登録
* 日記や振り返りの入力
* Markdownファイルのインポート
* CSV形式のデータ取り込み
* 将来的なAI連携による会話・記録分析

成長判定

経験の登録時に以下を分析する。

* 経験の種類
* 挑戦の難易度
* 継続性
* 本人の努力
* 結果
* 本人の感情や振り返り
* 過去の経験との関連性

評価はAIが提案し、ゲーム側のルールエンジンが最終的な能力変化を決定する。

AIが直接能力値を書き換える設計にはしない。

経験変換例

サッカーの試合：
身体能力・精神・意志力

画像制作：
創造性・知性・創造魔法適性

新しい知識の習得：
知性・探究心

人間関係の構築：
絆・感受性

新しい挑戦：
意志力・冒険心

経験値の付与量は固定ではなく、難易度・継続性・本人の振り返りを基に算出する。

同じ行動の繰り返しによる過剰な経験値獲得を防止する。

8. ゲーム内成長システム

現実の経験だけでなく、ゲーム内でも独立して成長できる。

学院生活

* 魔法授業
* 魔法薬学
* 魔法生物学
* 古代文字研究
* 魔法戦闘訓練
* 試験・課題
* 寮内イベント

探索

* 古代遺跡
* 秘密の部屋
* 禁書庫
* 魔法生物の生息地
* 未知の魔法領域

戦闘

* ターン制またはコマンド式を基本とする
* 習得魔法によって戦闘方法が変化
* 魔力・体力・精神力を管理
* 戦闘結果によって経験値やアイテムを獲得

9. 外見・進化システム

キャラクターの成長に合わせて外見を変化させる。

変化対象：

* 顔
* 髪型
* 髪色
* 目の色
* 服装
* ローブ
* 杖
* 装飾品
* 魔力のオーラ
* 魔法陣

重要：外見の変化は能力の変化と連動させる。

特定の魔法適性や実績を獲得することで、専用の衣装や覚醒形態を解放する。

既存のキャラクターデザインを無断で模倣しない。

10. 魔法生物・相棒システム

独自の魔法生物を収集・育成できる。

* 発見
* 飼育
* 信頼関係の構築
* 能力の成長
* 進化
* 特殊能力の習得

魔法生物は主人公の性格や魔法適性に応じて相性が変化する。

11. ストーリーシステム

メインストーリーは章ごとに進行する。

主人公の能力、性格、選択によってイベントの展開が変化する。

選択肢は単純な善悪ではなく、複数の価値観を表現する。

選択の履歴は保存し、後の物語に反映する。

メイン画面：

1. ホーム

4. 学院
5. 探索
6. 経験登録
7. 図鑑

ホーム画面では主人公の3Dモデルを中心に配置する。

14. データ管理・プライバシー

プレイヤーの現実の情報とゲーム内データを分離する。

* 元データの保存
* AIによる分析結果の保存
* プレイヤーによる修正機能
* 使用データの確認機能
* データのエクスポート
* バックアップ
* データの削除
* 外部AIへの送信前の確認

センシティブな個人情報は原則として育成データに使用しない。

16. 完成時の理想像

ARCANA ACADEMYは、単なるゲームではない。

プレイヤーが現実で経験を積むほど、ゲーム内の魔法使いも成長する。

ゲーム内で新しい挑戦をすることで、プレイヤー自身も楽しみながら新しい経験を得られる。

長期間にわたって育成することで、世界に一人だけの魔法使いが完成する。

最終コンセプト：

「あなたが生きた時間が、その魔法使いの歴史になる。」

付録A. ルールの仮パラメータ(実装側で決めた値。GDDに数値の定めがないもの)

GDDの方針(上限を設ける・難易度/継続/振り返りで算出・繰り返しの過剰獲得を防ぐ)に沿って、Phase 1で次の値を仮に置いた。値は src/game/growth/rules.ts にまとまっている。変えるときはここと CHANGELOG を更新する。

* 初期ステータス:7能力すべて10(初期診断はPhase 3)
* 難易度ごとの基本ポイント:1→1 / 2→2 / 3→3 / 4→5 / 5→8
* 継続ボーナス:かけた時間120分で最大+50%(時間に比例)
* 振り返りボーナス:30字以上で+20%
* 繰り返しの抑制:同じ種類・同じタイトルの経験を直近7日でn回反映していたら ×1/(1+0.5n)
* 能力への配分:経験の種類ごとに合計1.0(GDD 7章の変換例に沿う)
* 1回の経験で1能力が上がる上限:3
* 高い能力ほど伸びにくい:×(100−現在値)/100、上限100
* 偏りの抑制:平均より30以上高い能力は伸びが半分
* 経験値:成長ポイント×10
* 次のレベルまでの経験値:100+50×(レベル−1)
* 性格・魔法適性:Phase 1では値を決めず、根拠(経験の数・兆し)だけを記録する(Phase 3で形成・診断)
