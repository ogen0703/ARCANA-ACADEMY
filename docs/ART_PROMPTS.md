# ARCANA ACADEMY 画像プロンプト(ChatGPT用)

画風はGDDの「写実的ダークファンタジー」に合わせ、全画像で共通の【共通スタイル】を先頭に付ける。
既存の小説・映画・ゲームの固有の意匠(校章・制服・建物・キャラクター)は使わない。主人公はオリジナル(写真は使わない)。

## 共通スタイル(毎回先頭に貼る)

```
【共通スタイル】写実的なダークファンタジーのコンセプトアート。映画のスチルのような質感、物理的に正しい光、細かな素材感(古い石、磨かれた真鍮、羊皮紙、ベルベット)。色調は深い藍・紫・夜の黒を基調に、ろうそくの琥珀色と金の差し色。霧と光の筋で奥行きを出す。オリジナルの世界観で、実在の作品・映画・ゲームの建物、紋章、制服、キャラクター、ロゴに似せないこと。文字・透かし・署名は入れない。
```
